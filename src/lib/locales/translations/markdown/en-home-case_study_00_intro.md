Aligning developers to a design system was always hard. AI made it universal.

At Vanilla Forums, I grew through two promotions: from themer to Application
Web Integrator to **Senior Front-End [abbr:R&D] Developer**. I played a key
role in shaping the founding principles of a token-based theming system that
decoupled design from implementation. It let teams ship updates and refactor
safely while staying compatible with Vanilla's entire existing client base.
The system is still in production today, and has let Vanilla refactor out a
good chunk of the legacy UI that had been there since the start.

I was on the founding team for the **Knowledge Base** UI (_React_), defining
styling and component patterns that shaped the shared theming model. The
token layer kept themes compatible with the **Forum** (_PHP_). Clients kept a
unified brand theme across both products.
