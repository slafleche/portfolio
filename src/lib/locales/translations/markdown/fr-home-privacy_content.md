Quand tu utilises ce formulaire de contact, je collecte :

- Ton nom
- Ton adresse courriel
- Ton message

### Ce que je fais avec tes informations

- Je les utilise juste pour te répondre
- C'est tout

### Ce que je fais pas

- Je t'ajoute pas à des listes de marketing
- Je garde pas tes informations dans une base de données
- Je partage pas tes informations avec personne
- Je les utilise pas pour autre chose

### Pourquoi ce formulaire existe

Ce formulaire existe juste pour pas afficher mon adresse courriel en ligne, mais
quand même te permettre de me contacter.

Si t'as des questions sur cette politique, gêne-toi pas pour me contacter avec
ce formulaire.
