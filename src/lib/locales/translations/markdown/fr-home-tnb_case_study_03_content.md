J’ai forké mon framework CLI personnel dans la stack de l’agence et y ai
ajouté des scripts sur mesure. Clonage MongoDB avec barrière de confirmation
typée. Provisionnement d’utilisateurs basé sur 1Password qui synchronise les
comptes développeur de l’équipe dans les bases de données locales et de
production. Un script de capture de logs Vercel câblé à un skill Claude,
pour qu’en cas d’échec de build, l’assistant lise les logs et fasse le
triage. Le tout portable à travers tout le portfolio client de l’agence.
