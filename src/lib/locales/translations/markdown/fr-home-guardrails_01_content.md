Par défaut, les assistants IA commencent chaque session sans aucun souvenir de
vous ni de votre projet. Je leur donne les deux. Les règles portent les
conventions ; les skills portent les workflows personnalisés ; certains skills
sont même liés à des fonctions CLI pour que l’assistant puisse exécuter ses
propres diagnostics quand quelque chose tourne mal. Certaines pièces vivent au
niveau système et me suivent dans n’importe quel projet ; d’autres vivent dans
le repo et accompagnent quiconque rejoint le projet.
