Du vrai travail backend sur le framework Payload. Une page admin sur mesure
qui trouve et corrige en masse les slugs incohérents, un problème récurrent
de qualité de données venant des imports CMS. Un utilitaire de recherche de
pages par bloc qui localise toutes les pages utilisant un type de bloc
donné, utile quand une équipe de contenu doit réindexer ou réparer un bloc
refactorisé sans grepper à la main. Du travail Node.js + TypeScript +
modèle de données Payload sur de vrais problèmes éditoriaux.
