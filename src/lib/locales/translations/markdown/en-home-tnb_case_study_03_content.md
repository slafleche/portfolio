I forked my personal CLI tooling framework into the agency's stack and added
agency-specific scripts. MongoDB cloning with a typed-confirmation safety
gate. 1Password-driven user provisioning that syncs the team's developer
accounts into both local and production databases. A Vercel deploy-log
capture script wired into a Claude skill, so when a build fails the
assistant reads the logs and triages. All of it portable across the
agency's full client portfolio.
