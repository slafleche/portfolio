Aligner une équipe sur un système de design était déjà difficile. Maintenant
que tout le monde a un assistant IA dans son workflow, c’est encore plus
difficile.

Je livre des systèmes de design intégrés de A à Z : tokens, composants et
API de composants, patrons d’accessibilité conformes WCAG, framework CSS
(sur mesure, basé sur une bibliothèque, ou les deux). Je collabore
étroitement avec les équipes design et produit pour garder la vision
intacte, de Figma jusqu’à la production.
