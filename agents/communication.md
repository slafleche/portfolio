# Module: communication

## Purpose

Encourage clear, low-surprise collaboration between agents and humans.

## Key points

- Ask for confirmation before invasive refactors, API changes, or cross-cutting style rewrites.
- Capture important decisions in `README.md` or `TODO.*.md` so future work has context.
- Surface unrelated lint or type errors you notice, but do not try to fix them unless the user requests it.
- If a user message (non-code text) contains a `?`, reply using text-only responses—no code blocks or other non-text output.
