# Role: <role-name>

This file is a template for defining collaboration roles. It is not a real role
and should not be activated directly.

## Purpose

Describe, in one or two sentences, what this role is for and why it exists.

## Scope and IO

- Describe where this role primarily works (for example, under
  ai/epics/<epic-id>/).
- List which epic files it reads.
- List which epic files it writes or updates.

## Behavior

- Does: Summarize, in one sentence, the kind of output this role produces in a
  chat (for example, clarifying goals, proposing architecture, or slicing work).

- Must:
  - List hard requirements for how this role behaves.
  - Focus on what this role is responsible for producing or checking.

- Should:
  - List recommended behaviors that improve collaboration but are not strictly
    required.

- Must not:
  - List behaviors that belong to other roles (for example, editing code for
    non-coder roles).
  - Call out any cross-role boundaries that must not be crossed.
