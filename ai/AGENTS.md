# Agent Instructions for `ai/` docs

This file applies to all documentation and planning files under `ai/` (epics,
TODOs, backlogs, primers, implementation notes, and plans).

## Docs safety and freshness

- Must: Before editing any markdown file (`*.md`) under `ai/`, re-read the
  entire file in this chat session and base changes only on that latest
  version, not on an earlier snapshot.
- Must: Avoid destructive edits to epics, TODOs, and backlogs (removing whole
  sections, headings, or checklists) unless the user explicitly asks for that
  change; prefer additive edits or small rewrites.
- Must: Do not replace a substantive doc with a stub or pointer file (for
  example, a single link to another doc) unless the user clearly approves that
  redirect in the current chat.
- Should: When restructuring an epic or TODO doc (moving sections, renaming
  headings), describe the intended new structure in chat first and wait for
  user confirmation before applying large structural changes.
